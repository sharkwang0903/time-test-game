# 1 秒鐘到底有多長？

「你以為自己的時間感很準，但真的是嗎？」是一個放在公司官網上的輕量級時間感小遊戲 Prototype。玩家在看不到計時資訊的情況下，只靠直覺判斷指定時間何時到達。

## 專案架構

```text
index.html        遊戲首頁與模式選擇
mode1.html        模式一頁面
mode2.html        模式二頁面
css/style.css     全站共用樣式
js/common.js      共用計算、格式化與評語邏輯
js/mode1.js       模式一流程與計時邏輯
js/mode2.js       模式二流程、計時與計分邏輯
README.md         專案說明
```

專案只使用 HTML、CSS 與 Vanilla JavaScript，沒有套件、建置流程、後端或資料庫。

## 模式一：你的時間感有多準？

選擇 1、3、5、10、30 或 60 秒，按下「開始」。畫面進入極簡計時狀態後，憑感覺在目標時間到達時按下「就是現在」。系統會顯示實際時間、絕對誤差、相對誤差、太早或太晚，以及對應評語。

## 模式二：時間感階梯

依序挑戰 1、3、5、10、30 秒，共五關、目標時間合計 49 秒。每關完成時不會顯示成績，避免玩家依上一關結果修正策略；五關全部完成後才一次公布總分與每關紀錄。

## 計分公式

每關的相對誤差：

```text
e_i = |t_i - T_i| / T_i
```

每關得分：

```text
p_i = max(0, 20 × (1 - e_i))
```

五關總分：

```text
P = p_1 + p_2 + p_3 + p_4 + p_5
```

每關最高 20 分，總分最高 100 分。JavaScript 內部保留完整精度，只有顯示時才四捨五入至小數點後 4 位。

## Timeout 規則

如果玩家在「目標時間 + 5 秒」後仍未按下「就是現在」，該回合會自動結束並標記為 `timeout`。Timeout 不會偽裝成玩家作答時間；模式二的 Timeout 關卡得分為 0 分。

## 如何執行

直接用現代瀏覽器開啟 `index.html` 即可開始遊玩，不需要安裝任何工具或套件。

主要計時使用 `performance.now()`，Timeout 使用一次性的 `setTimeout()` 控制；成績不依賴計時器累加。
